# Consulta Universal — downloads

Aqui fica sempre a versão mais nova do aplicativo.

## Baixar

**[Baixar a última versão](https://github.com/pablodutra5/consulta-universal-download/releases/latest)**

Na página que abrir, clique no arquivo `.exe` em **Assets**.

## Instalar

Abra o arquivo baixado. Ele instala por cima da versão anterior e mantém tudo o que você já tinha: tokens, domínios e sites publicados. Não precisa desinstalar nada antes.

O Windows mostra um aviso azul dizendo que não reconhece o programa, porque o instalador não é assinado. Clique em **Mais informações** e depois em **Executar assim mesmo**.

## Versão 1.0.2

O painel passou a aceitar o token de **qualquer conta Cloudflare**. Você cola o token, ele descobre de qual conta é e instala o servidor lá dentro. Dá pra ter várias contas na lista e trocar quando quiser.

Junto foi corrigido um problema sério: o botão **Reparar** apagava os registros de DNS que o próprio painel cria para servir o domínio raiz, o que derrubava o site publicado.

O passo a passo completo está no PDF que acompanha a versão, em **Assets**.
